# Project Mars Assets

This directory contains visual assets for the Project Mars project: brand logos and
icons, demo artwork, and application screenshots used across the repository,
documentation, and applications.

## Structure

```text
assets/
├── branding/
│   ├── svg/          # SVG vector sources
│   └── png/          # PNG raster exports generated by svg-to-png.sh
├── demo/
│   ├── svg/          # Demo artwork sources (terminal.svg, demo.svg)
│   ├── png/          # PNG exports of demo artwork + app screenshots
│   └── gif/          # Animated demo (demo.gif)
├── icons/
│   └── languages/    # Per-language icons (rust, python, r, julia, cpp)
│       ├── svg/      # 512x512 SVG sources
│       └── png/      # 512x512 PNG exports
├── svg-to-png.sh     # Convert every SVG to a sibling PNG
├── sync-assets.sh    # Sync branding into packages/landing/public/
└── demo/svg-to-gif.sh# Regenerate the demo artwork + gif
```

Every `*/svg/*.svg` under `assets/` is converted to a sibling `*/png/*.png`
by `svg-to-png.sh`, keeping each SVG's intrinsic size and aspect ratio.
PNG exports are checked in — regenerate them after editing an SVG.

## Branding assets

All brand marks live in `branding/` — SVG is the source of truth, PNG is the
raster export.

### `logo.svg` / `logo.png`

Primary Project Mars logo (planet + notebook `M` mark). Used in the repository README,
landing site, desktop application, and documentation.

### `logo-file.svg` / `logo-file.png`

File icon for `.mars` notebooks. Used by the VS Code extension file icon theme,
desktop file explorer, and IDE integrations.

### `logo-folder-close.svg` / `logo-folder-close.png`

Closed orange folder icon with the planet mark at the bottom right.

### `logo-folder-open.svg` / `logo-folder-open.png`

Open variant of the folder icon (Material Icon Theme geometry) for expanded
folder states.

### `og.svg` / `og.png`

Open Graph / social preview image (1280x640). Used for social media previews
and the README banner.

### `og-square.svg` / `og-square.png`

Square (1200x1200) social card variant for platforms that prefer square
preview images.

### `logo-mono.svg` / `logo-mono.png`

Single-color line-art mark (planet outline, orbit arcs, notebook `M`) using
`currentColor` — for dark UI chrome, monochrome contexts, and print. The SVG
defaults `color` to white; override via CSS `color` to recolor.

### `logo-horizontal.svg` / `logo-horizontal.png`

Horizontal lockup: planet mark plus "Project Mars" wordmark and tagline (1200x400),
for headers, docs, and presentations.

### `logo-favicon.svg` / `logo-favicon.png`

Simplified planet mark (64x64) readable at favicon sizes. Source for
`favicon.ico` / app icons in `packages/*/public`.

### `logo-file-document.svg` / `logo-file-document.png`

Generic document icon with the planet mark, for non-notebook files in file
browsers and docs.

### `logo-badge.svg` / `logo-badge.png`

Compact pill badge (360x96): planet mark + "Rust-powered notebook" caption,
for README embeds and docs.

## Demo assets

`demo/` holds the artwork used in the README [Demo](../README.md#demo)
section, showing Project Mars in real-life use:

- `svg/terminal.svg`, `svg/demo.svg` — terminal window mockups walking
  through a real CLI session: `mars --version`, `new`, `run` with cell
  outputs, `inspect`, `export`, and `kernel restart`.
- `png/terminal.png`, `png/demo.png` — raster exports generated by
  `svg-to-png.sh`.
- `png/desktop-welcome.png`, `png/desktop-overview.png`,
  `png/desktop-notebook.png`, `png/desktop-notebook-explorer.png`,
  `png/desktop-lab.png`, `png/desktop-lab-new-job.png` — application
  captures written directly by `scripts/sh/screenshot.sh` (1280x640 ratio,
  2x DPR).
- `gif/demo.gif` — animated terminal demo generated by `demo/svg-to-gif.sh`
  from `scripts/demo-sessions/mars.json`.

## Language icons

`icons/languages/` holds the 512x512 marks for every supported language
(Rust, Python, R, Julia, C++). SVGs are the source of truth; PNGs are
generated by `svg-to-png.sh`. The README shows them inline at 28px in the
"Supported languages" row — keep the SVG viewBoxes tight around the glyph so
downscaling stays crisp.

## Generating PNG assets

```bash
cd assets
./svg-to-png.sh
```

Requires `rsvg-convert` (librsvg): `brew install librsvg` on macOS,
`apt install librsvg2-bin` on Debian/Ubuntu.

## Other scripts

- `sync-assets.sh` — copies `branding/svg/logo.svg` and renders `og.png`
  (1200x630) plus `favicon.ico` into `packages/landing/public/`. Requires
  `rsvg-convert`; ImageMagick (`magick`) for the favicon.
- `demo/svg-to-gif.sh` — regenerates `demo/{svg,png,gif}` via the shared
  terminal-gif generator. Requires `rsvg-convert` and `ffmpeg`, and expects
  the sibling `hieudoanm` checkout that hosts `scripts/demo/`.

## Usage across the repository

- **README.md** — logo `branding/svg/logo.svg`, OG banner `branding/png/og.png`,
  Demo section images from `demo/png/`, language icons from
  `icons/languages/svg/`
- **Landing site** — package-local copies under `packages/landing/src/assets/`
- **Desktop app** — package-local copies under `packages/desktop/src/assets/`
- **VS Code extension** — package-local copies under `extensions/vscode/assets/`
- **Docs** — see [`docs/06-appendix/branding.md`](../docs/06-appendix/branding.md)

Package-local copies are intentional: each app bundles only the assets it
needs. When brand artwork changes, update `branding/` first, then sync the
copies into the consuming packages.

## Branding guidelines

- SVG files are the source of truth; regenerate PNGs after editing.
- Do not modify logo proportions, recolor elements, or add effects.
- Keep assets self-contained: no external fonts, images, or network references.
