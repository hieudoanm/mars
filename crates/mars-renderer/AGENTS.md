# mars-renderer — Output & Notebook Rendering

Renders notebook cells and `Output` values to HTML, Markdown, and PDF. Depends on `mars-core`, `mars-document`; uses `pulldown-cmark` and `ammonia`.

## Modules

- `markdown/` — `render_markdown` (pulldown-cmark → HTML, sanitised with ammonia), `render_markdown_notebook` (whole notebook → portable Markdown), `fence.rs` (fenced code blocks), `output.rs` (Output → Markdown equivalents).
- `html.rs` — `render_notebook`: standalone dark-themed HTML document with inline CSS and Rust syntax highlighting.
- `output.rs` — `render_output`: per-output HTML (text, error, HTML, image data-URI, table, LaTeX, chart SVG, mime bundle).
- `highlight.rs` — lightweight Rust syntax highlighter producing `<span>` markup (no external highlighting crate).
- `latex.rs` — `render_latex_static`: static KaTeX-free LaTeX rendering (currently `\frac{a}{b}` → fraction spans, everything else escaped).
- `chart.rs` — Vega-Lite-style JSON spec → SVG (`bar`, `line`, `point` marks).
- `pdf/` — hand-rolled PDF writer (no PDF dependency): `writer.rs` (PDF primitives), `page.rs` (pagination), `tokens.rs`/`wrap.rs` (text layout), `markdown.rs` (md→lines), `cell_*.rs` (per-cell renderers), `render.rs::render_pdf_notebook(notebook, page_size) -> Vec<u8>`.
- `util.rs` — `escape_html`, `image_data_uri`, `is_safe_image_type`, `extract_svg`, `has_visible_text`, `mime_value_to_string`.

## Rules

- All user-controlled content (cell source, outputs, metadata) must be HTML-escaped or ammonia-sanitised — never emit raw untrusted HTML.
- Only raster/SVG image MIME types pass `is_safe_image_type`; everything else degrades to a placeholder.
- Keep PDF output deterministic — no timestamps or random IDs in generated bytes unless intentional.
- The PDF module is intentionally self-contained; do not add a PDF crate dependency without discussion.

## Testing

```bash
cargo test -p mars-renderer
cargo clippy -p mars-renderer --all-targets -- -D warnings
```
